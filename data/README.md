# Data (not redistributed)

Place only images you have permission to use in the following folders:

```
data/presidential_doggy_door/
├── train/
│   ├── bo/         # target identity
│   └── not_bo/     # other identities
└── valid/
    ├── bo/
    └── not_bo/
```

The source archive contained 139 training samples (19 Bo, 120 not-Bo) and 30 validation samples (10 Bo, 20 not-Bo), excluding notebook checkpoints. The original training set and the NVIDIA DLI course notebooks are intentionally not included because the redistribution terms for the images and educational materials have not been verified. Ensure license, consent, provenance and split independence before using or publishing a dataset.

Do not automatically treat course validation images as an independent test set. Collect a separate held-out test set, ideally from distinct photo shoots/sources, before making generalization claims.
